# wimi Client 核心能力与验证状态

本文记录客户端主要功能、平台支持和验证状态。

## 状态口径

| 状态 | 含义 |
| --- | --- |
| 已验证 | 主要使用流程已经通过自动化或端到端验证。 |
| 部分验证 | 基本能用，但完整服务链路、异常场景或真机验证还需要继续完成。 |
| 待验证 | 功能尚未完成，或还没有可用的完整验证。 |

## 核心功能与能力

| 能力 | 状态 | 验证范围或当前边界 |
| --- | --- | --- |
| Linux 客户端与主要界面 | 已验证 | 可以构建和启动，已覆盖登录、聊天、联系人和设置等主要界面。 |
| 注册、验证码与登录 | 已验证 | 已覆盖客户端与认证服务之间的主要流程。 |
| 文本聊天 | 已验证 | 已覆盖连接聊天服务、发送和接收单聊消息，以及基本的消息确认。 |
| 本地消息与草稿保存 | 已验证 | 已覆盖本地保存会话、消息、草稿和待发送内容。 |
| 文件消息 | 部分验证 | 已具备文件发送和接收界面及本地进度保存。安卓端缺少验证。 |
| 桌面通知 | 已验证 | Linux 桌面环境已支持通知。 |
| Android 客户端 | 部分验证 | 已能构建 Debug 安装包；群聊等功能需要验证。 |
| Windows 客户端 | 待验证 | 尚未完成构建和运行验证。 |
| iOS 客户端 | 待验证 | 尚未完成构建、签名和真机验证。 |
| 公网使用安全 | 待验证 | 长期登录、加密连接和安全保存凭据仍待完善。 |

## 验证入口

| 命令或方式 | 覆盖能力 | 状态 |
| --- | --- | --- |
| `cmake --preset linux-debug`、`cmake --build --preset linux-debug`、`ctest --preset linux-debug` | Linux 客户端构建、基础功能和界面检查 | 已验证 |
| 客户端网络测试 | 注册、验证码、登录和聊天连接 | 已验证 |
| 真实服务集成测试 | 登录、单聊发送、接收和同步 | 已验证 |
| Android Debug 构建 | Android 安装包 | 部分验证 |

客户端的构建、运行和测试方式见 [客户端指南](client-guide.zh-CN.md)。
